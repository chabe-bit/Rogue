# Rogue 
A 2D traditional roguelike inspired by Dragon Quest III.

The project explores building game systems from scratch, including:

* Character creation and class selection.
* Personality test to determine character stat growth. 
* Menu and user-interface systems.
* Sprite and asset rendering.
* Camera movement and collision detection.
* Music, sound effects, and volume controls.
* Inventory, items, and rarity systems (in-progress).
* Battle system (in-progress).
* AI pathfinding (in-progress).

# Requirements 
* Windows
* GCC - MinGW or MSYS2
* GNU Make

# Build

```
# Clone
git clone https://github.com/chabe-bit/Rogue.git
cd Rogue

# Compile 
make

# Run the game 
cd build
./rogue.exe
```
